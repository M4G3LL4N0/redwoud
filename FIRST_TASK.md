# First Task

## Task
Build the first REDWOUD MVP shell as a visually compelling intelligence dashboard homepage.

## Why
This creates the first tangible version of the product and makes the idea real immediately.

## Scope
Likely files:
- README.md
- PRODUCT.md
- ARCHITECTURE.md

- use seeded mock data

- [ ] dashboard sections exist
- [ ] visual hierarchy feels premium
- [ ] mock data renders
- [ ] product direction is reflected clearly
- [ ] files changed are summarized
