# Setup Checklist

Use this when starting a brand new project from the starter.

## Local setup
- [ ] create the new project with init-new-project.sh
- [ ] enter the new folder
- [ ] run ./scripts/verify-repo.sh
- [ ] run make verify
- [ ] run git status

## Project setup
- [ ] fill out STARTUP_INTAKE_TEMPLATE.md
- [ ] update README.md
- [ ] update PRODUCT.md
- [ ] update ARCHITECTURE.md

## Save setup
- [ ] git add .
- [ ] git commit -m "Initial starter setup"
