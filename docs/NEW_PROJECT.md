# New Project Guide

Use this repository as the starting system for a new software project.

## Basic flow

1. Create a new folder
2. Initialize git
3. Copy this starter system into the new folder
4. Update:
   - PRODUCT.md
   - ARCHITECTURE.md
   - README.md
5. Run verification:
   - ./scripts/verify-repo.sh
   - make verify
6. Commit
7. Push to GitHub

## Rule

Do not connect the new project to production infrastructure until verification passes.
