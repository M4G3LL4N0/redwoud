# Copy To New Project Checklist

Use this starter when creating a new software project.

## Steps

1. Create a new project folder
2. Initialize git
3. Copy this starter system
4. Update PRODUCT.md for the new project
5. Update ARCHITECTURE.md for the stack
6. Run verification:

./scripts/verify-repo.sh
make verify

7. Commit
8. Push to GitHub

## Rule

Do not connect to production infrastructure until the repo verification script passes.
