# Master Prompts

Use these prompts with Cursor, Codex, or Aider.

## Repository inspection prompt

Read this repository and explain:

1. what the project is
2. how the workflow works
3. which files define architecture
4. what improvements you recommend

Do not change files yet.

## Feature implementation prompt

Implement a small feature.

Rules:

- inspect relevant files first
- explain plan before coding
- avoid unrelated edits
- summarize all changed files

## Bug fix prompt

Investigate and fix the bug.

Rules:

- explain likely root cause
- implement minimal fix
- summarize changes
