# AI Working Guide

This file is the short version of how AI agents should work in this repository.

## How to approach tasks
1. Read the task carefully.
2. Inspect relevant files before coding.
3. Restate the current state and implementation plan.
4. Make the smallest safe change.
5. Validate with scripts.
6. Summarize clearly.

## Priority order
1. Correctness
2. Architectural consistency
3. Minimal diff size
4. Testability
5. Maintainability
6. Speed

## Definition of done
- Acceptance criteria satisfied
- No unrelated files changed
- Validation run or explicitly explained
- Diff is reviewable
- Summary is complete
